# Changelog

## 1.2.0 — 2026-11-09

- Microsoft Edge Translator as primary engine, batched up to 40 texts per request
- Google Translate as fallback
- Works on Telegram Web A (`/a/`) and Web K (`/k/`), including link previews
- Below / Replace display modes, Re-translate button
- 19 target languages
- Caching, dedupe, retry with backoff
